- 根因：Vite 默认 `base: '/'`，`dist/index.html` 使用绝对路径 `/assets/...`；用户直接打开本地 HTML 文件时，浏览器去 `file:///assets/...` 加载资源 → 全部 404 → 白板。
- 修复：
  - `vite.config.js` 增加 `base: './'`，让构建产物使用相对路径 `./assets/...`。
  - `index.html` 增加内联 favicon，消除 `/favicon.ico` 404。
  - `src/components/BatchModal.jsx` 移除未使用的 `message as _m` 导入（antd v6 静态 message 已弃用）。
- 验证：
  - `vite build` 通过；用 puppeteer-core + 本机 Chrome 对 `http://localhost:4173/` 做无头冒烟测试。
  - 结果：页面渲染正常（4 Tab、5 行数据），`title` 正确，控制台/网络 **零错误**。
